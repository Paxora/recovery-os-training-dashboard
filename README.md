# Recovery OS Training Dashboard

手机优先的 Recovery OS 训练 Dashboard，采用固定报告版式，支持训练进度、动作重量、身体反馈与 Apple Watch 数据的设备本地保存。

## 在线访问

https://paxora.github.io/recovery-os-training-dashboard/

## 当前内容

- 今日训练卡与完成进度
- 动作组数、次数和组间休息
- 新动作的中文教学视频直达链接
- 本次重量记录
- Energy、酸痛和身体反馈
- Apple Watch 训练数据
- 系统判断与安全停止条件

数据保存在当前浏览器的本地存储中，不会自动上传。
